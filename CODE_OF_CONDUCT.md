# Code of Conduct

We want discussion and contribution to be welcoming and constructive. Be respectful, assume good faith, explain technical disagreements with evidence, and make room for different levels of experience. Harassment, discriminatory language, personal attacks, unwanted sexual attention, and publishing private information are not acceptable.

This applies to project discussions, issues, pull requests and other spaces where people represent Tonight’s Movie. Maintainers may edit or remove harmful content, close discussions or restrict participation when needed. If something needs attention, contact the maintainer privately through the GitHub profile [@tblt-gr](https://github.com/tblt-gr); include relevant links and avoid sharing sensitive information publicly. Reports will be handled as discreetly as practical.
